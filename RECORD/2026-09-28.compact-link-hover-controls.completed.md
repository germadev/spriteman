# Compact Link Hover Controls

## 1. Goal / Context
Make frame-link controls visually lighter and keep both side controls visible while either connector is hovered.

## 2. Tasks & Changes
- Reduced link controls to an 18 x 22 px transparent icon area.
- Removed background and border from the revealed resting state.
- Applied background and border only to the connector currently hovered or keyboard-focused.
- Kept both sibling connectors visible while either side has hover or focus.

## 3. Verification
- `npm test`: 81 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser style inspection confirmed transparent resting controls, one styled hovered control, and both connectors remaining visible and interactive.

Completed and verified.
