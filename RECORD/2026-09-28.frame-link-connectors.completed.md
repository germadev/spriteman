# Frame Link Connectors

## 1. Goal / Context
Replace Shift-based frame grouping with visible connectors between adjacent frames and group options for intermediate count, reference editing, and dissolution.

## 2. Tasks & Changes
- Added link buttons between every eligible adjacent frame pair.
- Linking inserts one intermediate frame and creates the interpolation group in one undo step.
- Added a compact group options menu for editing intermediate count, reference points, and dissolving the link.
- Added atomic group resizing with a minimum of one intermediate frame.
- Kept generated group names synchronized with resized endpoints.
- Removed the Shift range-selection grouping flow and its obsolete UI state.

## 3. Verification
- Added service tests for link creation, minimum intermediate count, resizing, and undo.
- `npm test`: 81 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification confirmed 23 connectors for 24 ungrouped frames, one-click creation of a 3-frame link, resizing from one to three intermediates, reference editing activation, and dissolution while preserving frames.

## 4. Status
Completed and verified.
