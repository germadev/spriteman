# Group Pill Name Boundary

## 1. Goal / Context
Prevent long interpolation group names from overlapping the start and end frame cells.

## 2. Tasks & Changes
- Anchored the group pill inside the intermediate-frame wrapper with fixed inline insets.
- Allowed the name to shrink and truncate while reserving fixed space for action buttons.
- Compacted group actions so add, remove, and ungroup controls fit in short groups.

## 3. Verification
- `npm test`: 78 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser measurement confirmed 2 px insets on both sides and truncation from 409 px of text to a 93 px name region.

## 4. Status
Completed and verified.
