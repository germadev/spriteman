# Hover Frame Link Overlays

## 1. Goal / Context
Show frame-link controls only beside the hovered frame and prevent them from changing timeline spacing.

## 2. Tasks & Changes
- Render eligible left and right link controls inside each standalone frame wrapper.
- Position connectors as overlays centered on frame edges.
- Reveal connectors only while the frame or connector has hover/focus.
