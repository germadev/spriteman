# Hover Frame Link Overlays

## 1. Goal / Context
Show frame-link controls only beside the hovered frame and prevent them from changing timeline spacing.

## 2. Tasks & Changes
- Moved link controls inside each standalone frame wrapper as absolute overlays.
- Added eligible left and right connectors for the hovered or keyboard-focused frame.
- Hid connectors at rest with disabled pointer events.
- Centered each connector over its corresponding frame boundary without consuming reel width.

## 3. Verification
- `npm test`: 81 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser measurement confirmed identical frame positions before and after hover.
- Browser verification confirmed zero visible connectors at rest, exactly two around an eligible middle frame on hover, and successful linking from the left connector.

## 4. Status
Completed and verified.
