# Layer Opacity and Topbar Settings

## 1. Goal / Context
Simplify layer controls and move canvas resolution and animation speed into compact topbar dropdowns.

## 2. Tasks & Changes
- Removed layer Z labels and move-up/move-down buttons from the hierarchy list; drag and drop remains the ordering mechanism.
- Added a compact per-layer opacity dropdown with 100%, 75%, 50%, 25%, and 0% options.
- Added `ProjectService.setLayerOpacity()` with clamping, undo support, serialization, frame invalidation, and engine reload integration.
- Applied layer opacity during raster composition so canvas and timeline thumbnails reflect the selected value, including alpha blending over lower layers.
- Removed the sidebar `.settings-wrapper`, its component mount, state synchronization, and unused CSS import.
- Converted the topbar size and FPS badges into compact dropdowns using the existing project, canvas, animation, and persistence callbacks.
- Kept pixel zoom in the canvas toolbar.
- Added localized opacity control titles.
