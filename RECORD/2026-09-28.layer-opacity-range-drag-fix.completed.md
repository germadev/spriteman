# Layer Opacity Range Drag Fix

## 1. Goal / Context
Prevent the layer row from being dragged while adjusting its opacity range control.

## 2. Tasks & Changes
- Disabled native row dragging while that layer's opacity popover is open.
- Preserved layer reordering after the opacity popover closes.
- Preserved live opacity range input updates.

## 3. Verification
- `npm test`: 75 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification at `http://127.0.0.1:3020/#tabs=sample_walk` confirmed the open opacity row has `draggable=false`, range input updates remain reactive, and range interaction emits no layer `dragstart` event.

## 4. Status
Completed and verified.
