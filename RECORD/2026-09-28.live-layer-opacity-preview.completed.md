# Live Layer Opacity Preview

## 1. Goal / Context
Apply layer opacity continuously while the range control is dragged without creating an undo step for every input event.

## 2. Tasks & Changes
- Applied opacity changes on every range input event so the layer and canvas update before release.
- Added explicit opacity edit sessions that group continuous updates into one undo step.
- Deferred project persistence until the range gesture finishes or the opacity popover closes.
- Preserved the drag protection on the layer row while the opacity popover is open.
