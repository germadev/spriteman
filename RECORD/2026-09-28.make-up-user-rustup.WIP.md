# Make Up User Rustup

## Goal / Context
Allow `make up` to prepare the WASM Rust target on a machine where the user has no administrator permissions and Rust is currently installed through Homebrew without the WASM target.

## Tasks & Changes
- Bootstrap rustup into the user's home directory when it is unavailable.
- Add the `wasm32-unknown-unknown` target through the user-local rustup installation.
- Preserve the existing WASM watcher and Vite startup flow.
