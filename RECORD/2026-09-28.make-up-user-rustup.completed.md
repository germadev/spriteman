# Make Up User Rustup

## Goal / Context
Allow `make up` to prepare the WASM Rust target on a machine where the user has no administrator permissions and Rust is initially installed through Homebrew without the WASM target.

## Tasks & Changes
- Bootstrap rustup into the user's home directory when it is unavailable, without sudo or system writes.
- Add the `wasm32-unknown-unknown` target through the user-local rustup installation.
- Replace unsupported `wasm-pack --watch` usage with a timestamp-based watcher that rebuilds the development WASM package when Rust sources or Cargo manifests change.
- Preserve coordinated cleanup for the watcher and Vite development server.

## Verification
- `make -n up` expanded successfully.
- `make up` installed rustup and the WASM target in the user's home directory.
- The initial WASM build completed successfully.
- `src/wasm/pkg/spritemotion.js` was generated.
- `http://localhost:3000/` returned `HTTP/1.1 200 OK`.
- `git diff --check` passed during validation.
