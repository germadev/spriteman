# Make Up WASM Watch

## Goal / Context
Make `make up` install missing dependencies, build the development WASM package, and rebuild it when Rust sources change while the Vite development server runs.

## Tasks & Changes
- Update the Makefile development target to depend on dependency installation.
- Run `wasm-pack` in development watch mode and coordinate its lifecycle with Vite.
- Wait for the generated WASM JavaScript package before starting Vite.
