# Make Up WASM Watch

## Goal / Context
Make `make up` install missing dependencies, build the development WASM package, and rebuild it when Rust sources change while the Vite development server runs.

## Tasks & Changes
- Made `up` depend on `install`.
- Added `wasm-pack build --dev --watch` to rebuild the generated package when Rust sources change.
- Added a wait for the generated WASM JavaScript package before starting Vite.
- Added cleanup traps for the WASM watcher and Vite process.
- Made `wasm-pack` resolution include `~/.cargo/bin`.
- Added detection for the `wasm32-unknown-unknown` Rust target, with automatic `rustup target add` when rustup is available and an actionable message otherwise.

## Verification
- `make -n up` passed and showed the expected dependency, watcher, wait, and Vite commands.
- `make up` reached the dependency check and correctly reported that this Homebrew Rust installation lacks `wasm32-unknown-unknown`.
- `git diff --check` passed.
- Full WASM/Vite startup is pending installation of the missing Rust target.
