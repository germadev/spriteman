# Multi-format Export Modal

## 1. Goal / Context
Replace direct JSON export with an export modal supporting frame, animation, and project targets across SVG, Spritemotion, Lottie, ICO, and ANI formats.

## 2. Tasks & Changes
- Added a native-dialog export modal with separate content and format choices.
- Implemented the compatibility matrix:
  - Selected frame: SVG or ICO.
  - Active animation: animated SVG, Lottie JSON, or Windows ANI.
  - Complete editable project: Spritemotion JSON.
- Added pure export helpers that read and composite the active clip from v2 encoded cels.
- Compact same-color horizontal pixel runs into SVG paths and Lottie rectangle shapes.
- Added self-contained looping SVG animation output.
- Added Lottie 5.12.2 shape-layer output with discrete frame in/out ranges for LottieFiles-compatible playback.
- Added ICO output with a lossless PNG payload and a valid icon directory.
- Added Windows ANI output using a RIFF/ACON container, animation header, rate/sequence chunks, and embedded ICO frames.
- Added asynchronous export state, duplicate-click prevention, safe filenames, localized descriptions, and modal error handling.
- Documented the export matrix in README.md.
