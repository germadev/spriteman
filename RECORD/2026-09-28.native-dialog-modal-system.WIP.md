# Native Dialog Modal System

## 1. Goal / Context
Replace browser system dialogs and div-based modal overlays with reusable jq79 components built on the native `<dialog>` element and named slots.

## 2. Tasks & Changes
- Create a generic slotted modal component.
- Migrate the project modal to the generic component.
- Replace animation prompts and storage alerts with an application text modal.
- Preserve Escape, backdrop, focus, localization, and existing workflows.
