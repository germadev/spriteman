# Native Dialog Modal System

## 1. Goal / Context
Replace browser system dialogs and div-based modal overlays with reusable jq79 components built on the native `<dialog>` element and named slots.

## 2. Tasks & Changes
- Added `Modal.html`, a generic native dialog with jq79 `header`, default, and `footer` slots.
- Centralized `showModal()`/`close()`, Escape handling, backdrop clicks, close button behavior, modal focus, and accessibility labels.
- Added `TextModal.html` for reusable text input and message dialogs.
- Migrated `ProjectModal` from a div backdrop to the generic modal component, projecting tabs, form/list content, and contextual footer actions.
- Replaced system prompts for creating and renaming animations with `TextModal`.
- Replaced storage failure `window.alert()` with `TextModal`.
- Added localized confirm, cancel, dialog title, save error title, and create-animation labels.
- Kept `deferredPrompt.prompt()` because it is the browser PWA installation API, not an application dialog.
- Published new animation array references after add/rename so modal-confirmed changes refresh timeline tabs.
