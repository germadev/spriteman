# Non-blocking Opacity Preview

## 1. Goal / Context
Keep layer opacity dragging responsive by avoiding full-project recomposition, WASM reloads, and persistence work for every range input event.

## 2. Tasks & Changes
- Limit live opacity preview recomposition to visible frames.
- Coalesce range input updates to one operation per animation frame.
- Defer full recomposition, WASM reload, and debounced idle save until the gesture ends.
