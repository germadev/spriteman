# Non-blocking Opacity Preview

## 1. Goal / Context
Keep layer opacity dragging responsive by avoiding full-project recomposition, WASM reloads, and persistence work for every range input event.

## 2. Tasks & Changes
- Added a focused opacity preview path that recomposes only the current frame and onion-skin frame during interaction.
- Coalesced rapid range inputs into one update per animation frame.
- Deferred full-frame recomposition and WASM reload until the opacity gesture finishes.
- Kept project persistence behind the existing 500 ms debounce and idle callback, with one save request per completed gesture.
- Preserved a single undo step for the complete opacity gesture.
