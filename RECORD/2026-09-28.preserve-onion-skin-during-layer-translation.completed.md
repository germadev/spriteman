# Preserve Onion Skin During Layer Translation

## 1. Goal / Context
Keep the onion-skin overlay visible while a layer or loose pixel is translated.

## 2. Tasks & Changes
- Changed `CanvasService.setFramePixels()` so an omitted onion argument preserves the current onion buffer, while explicit `null` still clears it.
- Updated layer translation and loose-pixel movement to replace only the current composited frame during incremental movement.
- Preserved the existing layered project model: `ProjectService` continues recomposing the current frame from per-layer pixels, while `CanvasService` keeps current-frame and onion-frame composites in separate buffers.

## 3. Verification
- `npm run typecheck`: passed.
- `npm test`: 64 web tests and 13 Rust tests passed.
- Browser verification with an active onion overlay and Shift+drag measured 144 onion-colored canvas pixels before, during, and after layer translation.

## 4. Status
Completed and verified.
