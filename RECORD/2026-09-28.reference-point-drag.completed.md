# Reference Point Drag

## 1. Goal / Context
Allow start and end reference markers to be dragged directly without moving or painting the sprite.

## 2. Tasks & Changes
- Added a dedicated reference drag state with priority over layer movement, pan, loose-pixel movement, and painting.
- Updated reference coordinates continuously during pointer movement and finalized them on release or canvas exit.
- Added lazy history capture so a complete drag creates one undo step and a click without movement creates none.
- Preserved debounced project persistence after the completed gesture.

## 3. Verification
- Added a service test covering multiple endpoint updates and one-step undo.
- `npm test`: 79 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification confirmed both origin and destination markers enter the grabbing state and move while the layer transform remains unchanged.

## 4. Status
Completed and verified.
