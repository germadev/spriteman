# Reference Point Interpolation

## 1. Goal / Context
Replace the single interpolation-group pivot workflow with removable reference points that pair start and end positions and guide intermediate pixels.

## 2. Tasks & Changes
- Added persistent `reference_points` with start and end coordinates to frame groups.
- Added inverse-distance weighted deformation so nearby points influence each pixel more strongly.
- Kept legacy group pivots readable as stationary references.
- Added numbered origin/destination vectors to the canvas.
- Added timeline controls and canvas interactions to create, select, reposition, and remove references.
- Updated localized labels and the v2 format documentation.

## 3. Verification
- Added tests for multi-point deformation, stationary anchors, and v2 serialization.
- `npm test`: 78 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification confirmed group creation, reference origin creation, destination placement, endpoint markers, removal without ungrouping, and bounded group-pill layout.
