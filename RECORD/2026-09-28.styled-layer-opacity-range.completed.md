# Styled Layer Opacity Range

## 1. Goal / Context
Replace the native layer opacity select with a styled dropdown containing a continuous range control.

## 2. Tasks & Changes
- Replaced the native select with a compact percentage button and chevron.
- Added a styled popover with a 0-100 range, live percentage output, endpoint labels, custom track, and custom thumb.
- Added outside-click dismissal through a backdrop and Escape-key dismissal.
- Kept a local draft while dragging and committed only on the range change event to avoid excessive history entries, WASM reloads, and saves.
- Preserved the `.layer-opacity-select` class on the trigger for compatibility.

## 3. Verification
- `npm test`: 66 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification at `http://127.0.0.1:3011/#tabs=sample_walk` confirmed:
  - The popover opens at the layer control and remains inside the viewport.
  - The live output changed to 37% during input while the persisted trigger remained unchanged.
  - The trigger and inspector updated to 37% after commit.
  - Clicking the backdrop closed the popover and reset `aria-expanded` to false.
  - Visual inspection confirmed the popover does not resize or overlap the active layer row incoherently.

## 4. Status
Completed and verified.
