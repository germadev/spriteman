# SVG Icon System and Focus Reset

## 1. Goal / Context
Replace text symbols and emoji-based application icons with consistent SVG icons, remove focus outlines globally, and complete the box-sizing reset.

## 2. Tasks & Changes
- Add a reusable SVG icon component based on familiar Lucide icon geometry.
- Replace topbar, timeline, tabs, project, hierarchy, palette, and export modal symbols where appropriate.
- Remove decorative emoji from localized button labels.
- Apply `box-sizing: border-box` to elements and pseudo-elements.
- Remove focus outlines while retaining non-outline visual states.
