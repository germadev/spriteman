# SVG Icon System and Focus Reset

## 1. Goal / Context
Replace text symbols and emoji-based application icons with consistent SVG icons, remove focus outlines globally, and complete the box-sizing reset.

## 2. Tasks & Changes
- Added a reusable `Icon.html` component with familiar Lucide-style SVG geometry.
- Used jq79's supported exclusive `:if` / `:elseif` / `:else` chain so each icon renders one geometry.
- Replaced Unicode/emoji icons in the topbar, export modal, timeline transport, animation tabs, project tabs, hierarchy controls, palette swap, project modal, and welcome screen.
- Removed decorative symbols from localized button labels; accessible names and tooltips remain textual.
- Added consistent icon/text alignment and responsive topbar spacing.
- Applied `box-sizing: border-box` to all elements and `::before` / `::after` pseudo-elements.
- Removed focus outlines globally and replaced the opacity range focus outline with a box-shadow state.
- Preserved the non-focus outline used to indicate selected frame ranges.

## 3. Verification
- `npm test`: 75 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully with 38 modules.
- Browser verification at `http://127.0.0.1:3019/#tabs=sample_walk` confirmed:
  - 36 SVG icon instances render exactly one branch each.
  - No invalid `:else-if` or residual `:elseif` attributes appear in the DOM.
  - No jq79 directive warnings occur on a clean load.
  - Focused controls compute to `outline-style: none`.
  - Elements and pseudo-elements compute to `box-sizing: border-box`.
  - The topbar fits without horizontal overflow at a compact viewport.
- Source audit found no remaining emoji or decorative Unicode icons in application templates/messages.

## 4. Status
Completed and verified.
