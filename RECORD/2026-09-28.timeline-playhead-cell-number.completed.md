# Timeline Playhead Cell Number

## 1. Goal / Context
Show which frame is currently being rendered during playback without changing the selected timeline frame.

## 2. Tasks & Changes
- Added `data-frame-index` attributes to regular and grouped intermediate frame cells.
- Added an independent `.is-playhead` state that is present only during playback.
- Styled the playhead cell number with an amber background and subtle ring, distinct from the blue selected-frame state.
- Updated the playhead and frame indicator directly by integer frame index because jq79 keyed loops do not reapply external reactive classes to retained cells.
- Limited playback updates to one class removal, one class addition, and one indicator text update per integer frame; thumbnails and reel data are not rebuilt.

## 3. Verification
- `npm test`: 69 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification at `http://127.0.0.1:3014/#tabs=sample_walk` confirmed:
  - With frame 5 selected, the playhead visited frames 5 through 24 and wrapped through 1 to 4.
  - The active selected cell remained frame 5 throughout playback.
  - The playhead class was removed after pausing.
  - The frame indicator followed the playback frame while playing and returned to frame 5 after pause.
