# Dissolve Group Removes Intermediates

## 1. Goal / Context
When an interpolation group is dissolved, remove the generated intermediate frames it represents while preserving its start and end frames.

## 2. Tasks & Changes
- Delete intermediate frames atomically with the group.
- Preserve boundary frames and return the new start index.
- Reset selection and reference-edit mode to the surviving start frame.
