# Dissolve Group Removes Intermediates

## 1. Goal / Context
When an interpolation group is dissolved, remove the generated intermediate frames it represents while preserving its start and end frames.

## 2. Tasks & Changes
- Removed all intermediate frames from back to front when dissolving a group.
- Preserved the start and end frame content.
- Grouped metadata and frame removal into one undo step.
- Reset reference mode and selected the surviving start frame.

## 3. Verification
- Added a service test covering frame removal, boundary content, group removal, and one-step undo.
- `npm test`: 83 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification confirmed dissolving a three-intermediate group reduced 27 frames to 24 and selected frame 1.

Completed and verified.
