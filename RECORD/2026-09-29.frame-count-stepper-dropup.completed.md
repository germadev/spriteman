# Frame Count Stepper Dropup

## 1. Goal / Context
Make the group count segment only open a compact dropup containing minus, editable count, and plus controls.

## 2. Tasks & Changes
- Replaced the inline numeric input with a number display button.
- Replaced quick presets with a segmented `minus | editable value | plus` dropup.
- Kept stepper changes local while the panel is open and applied them once on Enter or outside click.
- Added min/max disabling and automatic focus/select of the editable value.

## 3. Verification
- `npm test`: 83 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification confirmed exactly three dropup controls and no inline input in the group bar.
- Consecutive minus/plus changes kept the dropup open, and typing value 5 followed by Enter updated the group and closed it.

Completed and verified.
