# Reference Hover and Frame Count Dropup

## 1. Goal / Context
Make the intermediate-frame count editable through a dropup and clarify reference-point add, move, and remove interactions on the active boundary frame.

## 2. Tasks & Changes
- Replaced the native count select with an editable numeric input and upward quick-choice panel.
- Added endpoint-aware reference hit-testing and hover rendering.
- Added `copy` cursor for adding, `grab` cursor for existing points, click-to-remove, and drag-to-move.
- Allowed adding and removing references from either the selected start or end boundary frame.
- Replaced the dashed solid-color connector with a blue-to-red gradient.

## 3. Verification
- `npm test`: 83 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser verification confirmed the panel opens above the editable input and typed values resize the group.
- Both start and end frames showed `copy` on empty space, `grab` over a reference, and added/removed the selected endpoint reference.
- Canvas instrumentation confirmed gradient stops `#0ea5e9` at 0 and `#e43b44` at 1.

## 4. Status
Completed and verified.
