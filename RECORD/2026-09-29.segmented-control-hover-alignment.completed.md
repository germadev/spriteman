# Segmented Control Hover Alignment

## 1. Goal / Context
Refine the interpolation-group segmented control hover behavior, spacing, count alignment, and dissolve color.

## 2. Tasks & Changes
- Moved hover scaling from the whole button to its icon.
- Added exact one-pixel gaps between all four segments.
- Centered the frame-count text with flex alignment and explicit line height.
- Changed dissolve hover background to firebrick.

## 3. Verification
- `npm test`: 83 web tests and 13 Rust tests passed.
- `npm run build:web`: production bundle built successfully.
- Browser measurements confirmed the button remains 18 x 20 px while its icon scales by 1.18.
- Measured segment gaps were exactly 1 px and count text was vertically centered within 0.2 px.
- Dissolve hover resolved to `rgb(178, 34, 34)` (`firebrick`).
