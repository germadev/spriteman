# Unclipped Frame Count Dropup

## 1. Goal / Context
Prevent the intermediate-frame count dropup from being clipped by the horizontally scrolling timeline reel.

## 2. Tasks & Changes
- Moved the quick-choice panel outside the reel overflow context.
- Rendered one fixed-position dropup above the active numeric input.
- Preserved editable input, quick choices, active-value styling, and blur dismissal.

## 3. Verification

- `npm run build:web`: production bundle built successfully.
- Browser measurement at a 677 x 541 viewport confirmed the full 112 x 90 px panel stays inside the viewport, ends 5 px above the input, and extends above the reel without clipping.
