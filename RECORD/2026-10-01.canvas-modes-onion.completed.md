# Work Record: Canvas Modes and Previous-Frame Onion Skin (Completed)

## Goal / Context
Make onion skin reference only earlier editable frames, replace implicit Shift/Ctrl drag actions with explicit canvas controls, and simplify the layer sidebar.

## Tasks & Changes
- Onion skin walks backward through the active timeline, skipping generated intermediate frames of any layer group. The opacity preview uses the same frame selection.
- Removed the layer inspector panel and its mounting/synchronization. The select-all button now shows an All label.
- Added bottom-left canvas controls: Shift selects the layer target instead of a pixel; Ctrl switches from painting to moving. Keyboard modifiers work temporarily and buttons can toggle the modes for touch use.
- Move mode moves a selected area, a loose active-layer pixel, or the active layer depending on selection and target. Painting and selection without move mode remain intact.
- All-layer selection disables single-layer movement controls and gestures.
