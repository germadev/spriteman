# Spritemotion Roadmap Snapshot - 2026-09-30 (Extended Tools)

## Completed Work

- Pencil, bucket fill, eyedropper, line, rectangle, circle, triangle, and selection tools are available in purpose-based editor controls.
- A split-button dropdown selects shapes and recalls the most recent shape. Selection supports moving, copying, cutting, pasting, and deleting active-layer pixels.
- Color replacement and symmetry use the hierarchy's select-all button for current-frame all-layer scope, with single-layer tools disabled in that mode.
- Grouped-frame onion skin references the opposite group endpoint.

## Planned Work

- Add automated browser gesture tests for shape previews, touch selection, and cross-layer color replacement.
- Refine pixel-perfect shape rasterization and selection handling at canvas boundaries.
- Continue easing controls, export, and atlas import work.

## Pending & Backlog

- Define brush-size variants and symmetry painting as a persistent live mode.
- Improve narrow-screen sidebar navigation and storage recovery.
